# BrightAce V66 — Country Picker Search + Branded Popup Fix

Base package: BrightAce V66 — Real Bundled Country Flags Fix

## Changes
- Replaced the native country dropdown presentation with a custom BrightAce-branded country picker.
- Added a searchable country field at the top of the popup.
- Every country result displays the bundled BrightAce flag glyph, country name, ISO country code, and dial code.
- Preserved alphabetical country ordering.
- Preserved the existing E.164-style phone value behavior and country inference.
- Added keyboard support and outside-click/Escape closing.
- Kept the flag font local; no external flag CDN is required.
- Updated the phone-picker cache version to `20261003b`.

## Flag source
The bundled flag font is the same BrightAce-subsetted Twemoji Mozilla color font already present in the base package. Attribution is in `assets/fonts/BRIGHTACE-FLAG-ATTRIBUTION.txt`.
