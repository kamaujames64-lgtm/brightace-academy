# BrightAce Academy — Tutor Directory / Scheduling One-Change Update

## Requested behavior implemented
- Admin Tutor Dashboard now has a dedicated **CLIENT ↔ TUTOR — WEBSITE ONLY** tab.
- The full client/tutor work-comment conversation is shown there, with request-level drill-down.
- Client ↔ Tutor communication remains website-only; it is not WhatsApp.
- Client ↔ Admin and Admin ↔ Tutor remain separate channels.
- Tutor dashboard detail modal z-index was corrected so clickable cards/details actually open above the dashboard modal.
- Attachment OPEN/DOWNLOAD links are opened in a new tab safely.
- Tutor-controlled availability scheduling has been removed from the tutor portal.
- Tutor profile page is now Profile only.
- Admin Scheduling no longer checks or requires tutor availability.
- Appointment process is now: website messaging agreement → Admin creates appointment → Admin adds Zoom link → client and tutor receive/see the appointment.
- Tutor availability write endpoint is blocked to prevent old clients from restoring the removed workflow.
