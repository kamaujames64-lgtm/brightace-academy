How paid resource delivery works

  1. Put the resource file in Google Drive.
  2. Set the Drive file to Anyone with the link — Viewer if you want a public buyer to open/download it after payment.
  3. Add it here with the exact Drive file ID and a USD price.
  4. Publish it in the paid catalog. The public promotional page does not list paid resources; direct checkout links remain a separate legacy flow.
  5. After Paystack confirms the payment, the buyer receives the Drive file link.

BrightAce does not automatically change Google Drive sharing permissions. This avoids accidentally making a private file public.
